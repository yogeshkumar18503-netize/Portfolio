## Live Preview & Quick Start

### Method 1: Instant Local Run (Python Server — Zero Setup Needed)
Since Python is already available on your machine, simply run:
```powershell
python -m http.server 5173
```
Now open **`http://localhost:5173`** in Chrome, Edge, or any modern web browser!

### Method 2: Direct Double-Click
You can also directly double-click `index.html` in this folder to open the website directly in any browser.

### Method 3: Deploy to GitHub Pages (Free Hosting)
1. Push this folder to a GitHub repository: `https://github.com/yogeshkumar0503/portfolio`.
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
4. Your portfolio will be live at `https://yogeshkumar0503.github.io/portfolio` within 60 seconds!
